# HireScope

HireScope is a Toronto-focused developer job market analytics platform.

It collects developer job postings and helps users explore hiring trends based on company, position, salary, location, work type, and technology stack.

## Project Goal

The goal of HireScope is to make developer job market data easier to search and understand.

Instead of only listing job postings, HireScope analyzes data such as:

- Most in-demand technologies
- Remote, Hybrid, and On-site job ratios
- Companies hiring the most developers
- Salary trends
- Junior, Intermediate, and Senior position trends
- Job market changes over time

## Initial Coverage

- Toronto
- Greater Toronto Area
- Developer and software-related positions

## Core Features

- Collect developer job postings
- Search jobs by keyword
- Filter by location
- Filter by work type
- Filter by technology stack
- View job details
- Save bookmarked jobs
- View hiring statistics and charts
